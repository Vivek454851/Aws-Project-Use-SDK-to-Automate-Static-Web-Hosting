# Automate Static Web Hosting using AWS SDK

## Project Overview
Mini project for automating static website hosting on Amazon S3 using Python and boto3 SDK.

## AWS Services Used
- Amazon S3
- boto3

## Features
- Automatic S3 bucket creation
- Upload static website files using Python
- Enable static website hosting
- Configure public access permissions
- Fast and simple cloud deployment

## Tech Stack
- Python
- boto3
- AWS Cloud Services

## Architecture
Python Script → boto3 SDK → Amazon S3 → Static Website Hosting

## Purpose
This project automates the process of hosting a static website on Amazon S3 without manual configuration.

## Setup Steps
1. Configure AWS CLI
2. Install boto3
3. Add website files to project folder
4. Update bucket name in script
5. Run Python automation script
6. Open S3 website endpoint in browser
